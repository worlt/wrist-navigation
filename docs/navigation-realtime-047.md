# 导航距离刷新 · 手机0.3.4 / 手环0.4.7本地候选

用户反馈：距离有时实时更新，有时要抬腕、屏幕闪一下后才变化。此前另有一加13（Android16 / ColorOS16、高德17.02.0.2010、手环应用0.4.6）左右转可用但直行缺失的反馈。本候选保留[手机0.3.3的自定义通知视图补读](phone-custom-notification-033.md)，并修改读取、唤醒同步和页面更新路径。没有这台设备的运行时间线，不能把闪屏归因于某个确定的固件缺陷。

## 确认的代码问题与修改

- 活动通知的补读原来跟随8秒发送心跳。如果高德或系统没有发出通知变更回调，距离可能等到下一次补读才发现。现在活动导航约每1秒补读；临近心跳时最短500ms。通知变更的150ms去抖保留，非活动轮询仍8秒。
- 手机收到手环ready原来直接重放缓存。现在优先安排立即重新读取高德通知，再走发送流程；监听未连接或同步关闭等无法安排读取的情况才使用已有发送路径。
- 手环接收后原来先通知页面再ACK。现在先发ACK再通知页面，ACK成功回调不额外同步通知页面，减少渲染与确认互相等待。
- 应用和页面唤醒可能同时查询连接并请求ready。现在1秒内合并恢复请求；连接正常时直接ready，手动重试继续显式查询。连接失败会重置合并时间，不阻止后续恢复。
- 同方向距离变化时，原来反复赋相同箭头图片、字体和辅助字段。现在只对变化的值赋值，避免距离刷新引发相同图片的重载。本次不靠反复切亮度强制刷屏。

1秒补读和发送心跳是两个独立策略：变化数据仍保持500ms最小发送间隔；相同活动内容仍8秒心跳，不会每秒发送相同导航包。隐藏页面继续接收并缓存到应用会话，重新可见时应用最新快照并请求手机新读取。导航页面可见且启用常亮时沿用现有常亮逻辑；不把此功能描述为后台或系统AOD实时显示。

## 将接收和页面更新分开诊断

手机导航消息增加可选displayDiagnostics布尔字段。新版手环可见导航页完成显示数据赋值后，按会话和编号最多报告一次display/applied；旧版手机或未带字段的数据不发送报告。隐藏、设置页、过期或退出请求不报告导航页面更新。报告失败不会改变ACK格式、断开导航或触发递归绘制。v1导航/ACK包格式及原包名、原配对签名保持兼容。

手机诊断把当前/历史ACK与当前/历史页面报告分别列出。ACK后下一帧已发送时才到达的旧页面报告保留为历史，不冒充当前帧。**页面报告只证明显示数据已提交到页面模型，不证明物理屏幕已刷新。**

| 现场证据 | 优先检查的环节 |
| --- | --- |
| 手机读取或解析的距离本身未变化 | 高德通知源、ColorOS提供的字段/视图、监听状态 |
| 解析变化，发送编号未推进或ACK持续缺失 | 节流/发送状态、SDK连接与手环运行状态 |
| 当前ACK已收到，页面报告仍旧或没有 | 页面隐藏、设置页、应用生命周期；旧版手环也没有此报告 |
| 当前ACK和页面报告都推进，但实际屏幕仍旧 | Vela原生渲染、固件调度与屏幕刷新；本地模型测试不能替代真机检查 |

诊断沿用内存保存、用户主动复制的边界，不自动上传路线或日志原文。

## 安装包与验证

双端配套为手机0.3.4/code19、手环0.4.7/code21，两端均需更新才能测试完整优化。完整字体版/无字体版手环包二选一。交付目录为outputs/candidates/realtime-20261118/，含原签名debug APK、两种原签名debug RPK、TESTING.txt、完整THIRD_PARTY_NOTICES.txt和SHA256SUMS.txt。此前手机0.3.3候选原包保留，当前正式Release仍v0.4.8（手机0.3.2/手环0.4.6）。

本地验证通过92项Android单元测试、140项Node测试、Android Lint（0错误/3既有警告）、原签名APK构建及完整版/无字体版RPK构建。实际RPK编译代码检查包含ACK先于页面报告、同方向距离变化不重赋箭头或切亮度、隐藏仅缓存/可见恢复、应用和页面同一唤醒只发一次ready。两RPK通过ZIP/签名内容/共享证书/嵌套签名校验；APK包名/code19/name0.3.4核对通过，签名证书与已发布手机0.3.2一致。记录在.local/realtime-20261118/。

这些测试使用模拟通知数据及原生接口，验证策略、编译包行为与签名，不能证明这台一加手机和手环上已解决、常亮后台成功或闪屏原因。本候选未提交/推送/发布/传设备/安装/真机验收。

## 真机对照

1. 双端更新，确认通知使用权、互联授权和同步开启。先保持手环导航页前台并开启现有常亮选项，记录同方向下实际距离变化、转弯后直行、导航结束。
2. 对照手腕放下/抬起、手机亮屏/锁屏/切后台，记录真实画面与手机读取、解析、发送编号、ACK、页面报告。进入设置后缺少导航页面报告是预期行为，退出设置应恢复最新数据。
3. 对照断连/重连和切回导航页面，确认唤醒后获取新距离；若仍卡住，停下后复制诊断，并附常亮/页面状态及真实画面，可删去道路名称。

高德实际发布距离的频率、Android对通知的暴露、SDK交付与手环固件调度共同决定端到端速度。补读不能从高德尚未发布的字段中造出新距离，也不按时间虚构米数倒数。固件暂停应用或屏幕刷新时，传输方式换成WebSocket也不能保证息屏实时显示。1秒是活动补读目标，不是端到端延迟承诺；更频繁读取可能增加手机CPU/耗电，尚无真机功耗测量。

候选版本码高于正式版本，常规覆盖不能直接降回旧版；如卸载后重装正式包，手机/手环设置需要重新配置，手机需要重新授权。无需重置设备或更换签名。
