# 一加13直行缺失 · 手机0.3.3本地候选

后续[手机0.3.4 / 手环0.4.7刷新候选](navigation-realtime-047.md)保留本次补读并增加距离刷新优化；以下是手机0.3.3候选的历史实现与验证记录，原包保留。

反馈环境：Android 16 / ColorOS 16，高德17.02.0.2010，手环应用0.4.6。用户报告左右转可显示，转弯后直行不显示。截图的手机导航卡片显示直行及距离，但本项目标准通知字段仅有固定步行导航提示，解析为unknown；消息#29在截图时尚未收到ACK。不能仅凭截图确定流体云具体数据结构或传输是否失败。

## 本地候选的作用

手机0.3.3/code18增加自定义通知视图补读，沿用手环0.4.6、v1通信格式、原包名和配对签名。只在高德标准字段没有明确方向、且通知为持续通知或已识别的活动导航时尝试补读；正常左右转和明确结束继续采用标准字段。三种RemoteViews分别读取可见TextView，不跨来源拼接，不从图标、剩余总里程或缺少转弯文字推测直行。

只读取由高德包提供的视图，视图不附着到界面、不调用点击或发送PendingIntent。最多遍历128节点、12层、32条文字，每条512字符；不完整来源不用于补读。多个完整视图的方向、明确距离或道路矛盾时保留标准结果，不任意选择旧转向。

诊断新增手机/Android/机型/高德版本、通知ID、解析文字来源、自定义视图存在与读取结果、扩展字段名称和类型。厂商私有字段值不展示，也不用于导航解析。仅处理高德，仅在内存保存，用户主动复制才进入剪贴板，不自动上传或记录路线原文。诊断有条数和长度上限，解析采用的通知优先保留。

## 验证与限制

本地通过88项Android单元测试、133项Node测试、Android Lint及原签名APK构建。新增14项覆盖直行补读、标准转向/结束保留、跨来源冲突、道路冲突、未完整读取、总里程误用、非高德/推广排除、隐藏旧文字和树遍历边界。Android API适配层通过编译/Lint；单元测试中的视图树为模拟数据，没有在这台一加上执行RemoteViews.apply。

这是一个针对Android自定义通知视图路径的候选，不是已确认的ColorOS16流体云私有字段适配。若系统没有向通知监听提供这些视图，或直行文字仅存在私有结构/系统页面，本版仍不能读取；诊断会帮助区分视图不存在、无可见文字、读取失败和来源冲突。不要声称已修复一加实机或Android16全部兼容。

## 用户验证

1. 仅在手机覆盖安装NAV-PHONE-033.apk，手环保持0.4.6；确认高德通知使用权、互联授权及同步开启。
2. 在安全位置由同行者操作手机，或停止行走后查看；分别记录左转时、转弯后直行时的同步诊断。
3. 若来源为contentView/bigContentView/headsUpContentView且解析显示直行和距离，再核对发送内容和相同编号ACK，以及实际手环画面。
4. 若仍未知，复制“直行时”的当前诊断反馈；可先删去道路名称。若有可用的高德流体云/实时活动开关，可临时关闭后对照普通通知，再恢复原设置。菜单位置和关闭后的行为以这台手机实际界面为准，不保证关闭即解决。
