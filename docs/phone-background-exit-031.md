# 手机后台与明确退出（手机 0.3.1 / 手环 0.4.6）

2026-11-12 修复手机 0.3.0 的退出联动误触发。手机升级为 0.3.1/code16；手环仍使用 0.4.6/code20，完整字体与无字体版均沿用现有通信格式。本次只需更新手机 APK，保留原包名及配对签名。

开启「退出手机应用时退出手环」后的行为：

| 操作 | 手环行为 |
| --- | --- |
| 回桌面、切到高德或其他应用 | 保持运行，后台导航同步和导航自动打开继续 |
| 锁屏、进入系统权限设置 | 不发送退出请求 |
| 手机页面旋转或配置重建 | 不发送退出请求，不重复触发进入联动 |
| 在手机主页面按返回键或完成返回手势 | 关闭手机页面，并请求退出手环 |
| 仅关闭设置弹层 | 不退出手机主页面或手环 |
| 快速重新进入手机应用 | 取消待退出请求，保持原有进入联动 |

两个联动开关继续独立保存、默认关闭。关闭退出联动时，返回关闭手机页面也不退出手环；后台同步服务保持运行。普通切后台会停止本次进入联动的有限重试，但不会屏蔽导航自动打开。已发出的 SDK 打开请求不能撤回，迟到成功仅在明确退出后才补偿退出。

代码将可见状态与明确退出分开：onStop 在非配置重建时更新后台状态，仅 isFinishing 时请求退出；Android 13 及以上注册返回回调，旧系统沿用 onBackPressed。phoneExitId、ACK、300ms 延迟、10 秒发送窗口与手环去重格式保持兼容。

修复前新增的两项回归测试均失败，分别覆盖后台退出请求和退出判断。修复后覆盖切换应用、后台重入、迟到打开、后台后明确退出、重复退出、开关变更、快速重入、过期及断连。本地自动检查记录见维护交接。
