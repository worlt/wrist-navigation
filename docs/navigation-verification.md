## 尚待真机确认

- 当前 0.4.0 已有维护者试用反馈；最大箭头、环岛数字与导航回归尚无逐项记录。可沿用 [10 Pro 移植说明](port-10pro.md) 中的检查项目，但应记录实际新版本。
- 当前三款附加字体实际切换、资源性能、最大字号滚动与重开后设置保存，详见 [字体说明](fonts.md)。
- 当前版本的长时间锁屏、导航结束、断连及离开页面后常亮释放。
- 重启、长时间离线/断连、无 USB 供电和深度 Doze 恢复。
- ACK 回程、耗电和其他手机/手环兼容性。

手机暂未记录到 ACK 不否定用户已经确认的实际显示。SDK 接受自动打开或发送请求也不能单独证明手环画面正确。
