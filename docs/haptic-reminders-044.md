## 安装和设置

这次需要一起更新手机 `NAV-PHONE-028.apk`（0.2.8 / code 13）和手环 `NAV-BAND-044.rpk`（0.4.4 / code 18），文件位于 `outputs/releases/v0.4.4/`。先核对同目录 SHA256SUMS.txt；手机覆盖安装 APK，手环用 AstroBox「快应用」覆盖安装 RPK，再恢复小米运动健康连接。均沿用原包名和签名证书，是已签名调试构建。

手环齿轮 → 导航设置 → 向下滑：

- **振动提醒**：点击切换开启/关闭，默认开启。关闭后开始、结束、转向、临近与手动试振均静默；已发出的系统振动不能撤回，尚未发出的第二下立即取消。
- **提醒震感**：轻柔为两次系统短振，明显为两次系统长振（默认）。两次调用起点分别间隔 350 / 1200 毫秒，实际长度由固件决定。
- **试振两下**：无需开始导航，按当前档位试振；总开关关闭时提示先开启。

总开关和档位自动保存在手环，与字体/箭头设置分开。App 先读取振动偏好再允许振动，避免启动时忽略已保存的关闭状态；读取尚未完成时收到的提醒不补播。存储读取失败回退当前默认并提示，不能保证故障时恢复历史设置。恢复默认会恢复振动开启、明显档。手机「手环振动提醒」开关也需开启才能接收导航振动；手机开关不控制手环主动试振。

## 提醒规则

| 事件 | 正常行为 |
| --- | --- |
| 开始导航 | 收到本次导航首条有效活动消息，振两下；直行或未知方向也可提示开始 |
| 开始时已是转向/已临近 | 合并为一组两下，不在同一条消息上连播多组 |
| 新转向 | 两下，沿用道路/出口/距离身份去重 |
| 临近路口 | 首次进入 30 米（默认）或 100 米（手机骑行选项）再两下 |
| 导航结束 | 明确收到结束信息，或确认高德通知持续消失后，两下；同次导航只提示一次 |
| 暂停、断连、通知权限异常、演示 | 不当作导航结束提醒；取消待播部分 |

手机进程内用 `navigationId` 标识一次导航，`navigationEnded` 标记确认结束；字段兼容现有 v1 通信。结束通知没有转向 ID 也能提醒。通知短暂消失后恢复不更换导航 ID；连续两次读取均无高德通知且相隔至少 5 秒才推断结束，当前常规轮询为 8 秒，因此此路径会有数秒延迟。存在无法解析的高德通知时不猜测结束；未观察到本次活动导航的手环不会仅因收到旧结束状态补振。

通知驱动不是路线引擎：中途接入时首次看到活动导航可能提示开始；应用进程重建会清空去重历史；快速结束后又开始且没有观察到中间状态时，不能保证识别两次独立行程。关闭任一导航振动开关期间仍消耗提醒机会，恢复时不补振。页面隐藏/销毁保持 App 的正常导航双振；只取消手动试振余下部分。过密提醒最多保留一组待播，不无限排队；固件挂起后明显迟到的第二下不补播。

## 强度能力和兼容

[Vela 官方 vibrator 文档](https://iot.mi.com/vela/quickapp/zh/features/system/vibrator.html)（2026-11-11 核对）没有为 `vibrate` 提供马达幅度参数，仅有 short/long。start/stop/getSystemDefaultMode 仅列 Watch S5 支持，不能推定 10 Pro 可用。因此本版提供短/长振震感选择，不声称可调整物理力度。

手机 0.2.6/0.2.7 配新手环仍有基础转向/临近提醒，但没有本轮导航开始/结束标识；要完整测试请用 0.2.8。手机 0.2.5 仍仅显示。息屏/回表盘的第二下、long 的实际震感、耗电和结束通知格式仍需真机；9 Pro 未回归。
