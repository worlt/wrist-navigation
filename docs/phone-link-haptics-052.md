# 手机联动双振修复043/052

发现：旧session收到phoneExitId时先取消振动，app-exit仅延迟300ms；打开联动没有对应提醒事件，导航不活动时没有开启动作双振。根据用户新需求修复这两条代码路径，不把它当作真机完整根因证明。

手机原生launch成功后产生10秒有效打开ID，随导航快照发送、匹配ACK后清除；失败/过期/迟到或隐藏后成功不生成打开提醒。v1扩展phoneOpenId校验非空/类型/长度，并禁止与phoneExitId同时出现；旧端继续渲染导航。

手环先ACK，按已读偏好和手机reminderEnabled双振；等待偏好时避免越过静音，迟到/过期不补振。打开与导航开始合并一组，重复帧不重振。正常退出先ACK、双振后关闭，轻柔约1秒/明显约2.7秒；重新进入取消关闭和第二振，通信断开不取消已接受的退出提醒，原生API缺失安全降级。强杀手机不能保证发送通知或手环关闭/振动。

回归：9个新增手环session测试、3个Android policy测试及源码/模拟版本回归；旧静音退出测试保持，ACK失败测试调整为只保留明确退出双振、不得另加断连提醒。两个实际编译RPK也检查打开/退出双振和ACK/去重/取消；本地183Node/141Android、Lint0错3旧警告。尚无本轮设备传输、安装或真机震感验收。

用户复测：配套手机043与手环052，开启需要的打开/退出联动和双端振动总开关；分别测试无导航时打开手机、主页面正常返回退出（不要强杀）、快速返回后重新进入、关闭振动总开关的静音。记录型号/固件与版本，出现问题复制无路线兼容诊断，不上传私人路线。
