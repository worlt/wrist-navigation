# 字体使用与验证

字体来源核对日期：2026-11-05；2026-11-12 补充手环 0.4.6 两版打包说明。下文三款内置字体适用于完整版源码、RPK 与网页预览。`NAV-BAND-046-NOFONT.rpk` 不包含三款字体或字体选择入口，仅引用设备系统字体，详见 [两版区别](wearable-variants.md)。

## 能否使用

三款内置字体均附有 **SIL Open Font License 1.1（OFL）**。该许可允许使用、嵌入、修改及随软件分发，包括商业软件；需要保留版权与完整许可、遵守保留字体名称等条件，不能把字体本身单独出售，也不能把字体改成项目的 MIT 许可。完整条款以各字体所附文件为准。

官方解释与完整条款：[OFL 官方站](https://openfontlicense.org/) · [OFL 1.1 正文](https://openfontlicense.org/open-font-license-official-text/)。

| 设置名称 | 实际字体 | 项目内家族名 | 完整许可 |
| --- | --- | --- | --- |
| 系统默认 | 手机或手环固件提供的系统字体 | `sans-serif` | 本项目只引用，不复制或分发系统字库 |
| 宋体 | 站酷小薇体 / ZCOOL XiaoWei | `BandSong` | [版权与 OFL](../wearable/src/common/fonts/BandSong-OFL.txt) |
| 楷体 | 霞鹜文楷轻便版 / LXGW WenKai Lite v1.522 | `BandKai` | [版权、保留名称及 OFL](../wearable/src/common/fonts/BandKai-OFL.txt) |
| 圆体 | 站酷庆科黄油体 / ZCOOL QingKe HuangYou | `BandRound` | [版权与 OFL](../wearable/src/common/fonts/BandRound-OFL.txt) |

“宋体 / 楷体 / 圆体”是界面分类，不表示分发 Windows 的 SimSun、KaiTi 或 YouYuan。修改字体家族已统一重命名为 BandSong / BandKai / BandRound；TTF 名称表保留上游版权和 OFL 信息，同目录保留完整许可。霞鹜字体声明的保留名称及附加许可原文也一并保留，不以附加许可替代 OFL 条件。

## 项目中的处理

- `tools/prepare-band-fonts.py` 保留 GB2312、拉丁字符、标点和界面字符，生成子集、重命名并保留版权记录；上游文件哈希和重建方式见 [字体资源来源](display-settings-024.md)。
- 完整版 RPK 随包包含三份 TTF 和对应的 `*-OFL.txt`；无字体版均不打包。源码浏览器预览内嵌同一套 TTF；各预览页附有“演示与许可声明”，可以直接展开完整版权及 OFL 文本，`site/` 另附这些文本文件。
- 设置原型 `settings.html` 仅通过 `local()` 尝试调用电脑字体，找不到时使用浏览器回退字体；因此它不能作为三款内置字体的视觉验证。实际内嵌字体请看 `preview.html` 的字体选择场景。

本轮检查对象为仓库现有 TTF、随附许可和生成网页，没有重新下载原始字体或重验历史来源哈希。现有 `BandKai-OFL.txt` 的版权头包含保留名称及附加许可，与 v1.522 标签下的许可头并非逐字一致；两者的许可正文均为 OFL 1.1。项目保留现有声明，并按 OFL 的改名条件分发子集，不依赖附加许可使用原保留名称。

## 手环上能否正常显示

**授权允许使用，不等于固件已验证。** 当前已检查名称表、字体资源、字符覆盖、编译后的选择与保存逻辑，浏览器能够加载内嵌字体。0.4.0 已有维护者在 K80U 上的试用反馈，但三款字体的实际加载与切换尚未逐项确认。

三款子集仍约为 6.23 MB、3.52 MB、5.52 MB，构建器提示均超过 1 MiB；加载耗时、内存占用和真实字形切换需要在手环确认。附加字体缺字时，相关导航或错误文字区回退到系统字体并保留原文；系统自身缺字的情况也要实测。

真机检查时依次选择系统默认、宋体、楷体、圆体，对照“直行200米”的字形；检查最大字号、长文字滚动、切换响应、重开后的设置保存与生僻字回退。未逐项确认前，发布说明应继续标注字体效果待真机验证。
