# 腕上导航 v0.4.8 · 手机同步诊断

2026-11-13。手机首页新增默认折叠的「同步诊断」，收起只占一行，展开可查看读取到的高德通知字段、解析结果、发送状态和手环确认状态，并复制当前诊断。远程反馈无需连接电脑即可提供四个阶段的信息。

**配套：手机0.3.2/code17，手环0.4.6/code20。已有手环0.4.6只需更新手机NAV-PHONE-032.apk。** 完整字体/无字体两份手环包沿用v0.4.7原字节；包名、配对证书保持，APK/RPK仍为原签名debug构建。

| 文件 | 用途 |
| --- | --- |
| NAV-PHONE-032.apk | 手机0.3.2，新增折叠诊断 |
| NAV-BAND-046.rpk | 手环0.4.6，完整字体，沿用原包 |
| NAV-BAND-046-NOFONT.rpk | 手环0.4.6，无字体，沿用原包 |

出现不同步时，先展开诊断、复制当前文本，再尝试重新连接。读取文字保留android.title/text/bigText等字段来源，解析显示方向和指引距离，未提取距离明确标注；读取失败时旧文字标记为历史。发送记录显示消息编号与已提交内容，旧ACK不确认新消息，新解析尚未发出会明确提示。SDK成功和手环ACK独立；ACK只证明手环应用收到消息，不证明实际画面已显示。

诊断只在手机进程内保留有限内容；不自动保存、上传或写入路线日志。用户点击复制才写入系统剪贴板，文本含手机型号/Android版本及导航文字，分享前请隐藏路线。折叠状态不展示导航原文。保留0.3.1的后台与明确退出区分。

本地验证：74项Android单元测试、132项Node测试、Android Lint和原签名APK构建；附件白名单、完整许可、包名/版本/原签名与SHA-256核对。默认折叠/展开/复制、厂商通知差异、一加13与K80U、锁屏和长时间导航仍需真机验证。本版增加排查能力，未声称修复一加的直行/距离不同步。其他手机兼容性未验收，9 Pro自0.3.3起未回归。正式Release/Latest仅代表分发状态。

实现与验收范围见[手机诊断说明](../phone-diagnostics-032.md)。
