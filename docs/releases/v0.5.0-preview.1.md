# v0.5.0-preview.1 · 9 Pro / 10 Pro 共用兼容试验

状态：**已公开发布 Pre-release，不设 Latest。** 发布地址：https://github.com/worlt/wrist-navigation/releases/tag/v0.5.0-preview.1。目标分支 preview/band9-band10-compat，不合入 main，不替换正式 Latest。

## Changed / Fixed

- 手环首屏就绪后才初始化互联及提醒存储，尝试规避 040→046 的早期 App 初始化风险；会话仍由 App 持有。
- 支持旧连接状态字符串、缺失检查接口；可选接口失败不阻断基础导航与 ACK。
- 版本和诊断消息支持一次 202 格式降级，手机严格单层封包解析。

## Added

- 手机“同步诊断”内：读取手环内部诊断、复制兼容诊断（无路线）。没有手环排查模式或新增手环诊断入口。
- 有界白名单内部记录、手机请求/设备/时限保护与收发拒收分类。
- [用户定位与反馈指南](../band9-band10-compatibility.md)：安装失败、闪退、接收、显示/振动问题的步骤和反馈模板。

手机 NAV-PHONE-040.apk（0.4.0/code25），手环 NAV-BAND-050-NOFONT.rpk / NAV-BAND-050.rpk（0.5.0/code24，二选一，推荐先无字体版）。包名与原配对签名不变，仍为 debug 构建。update.json、许可、TESTING、SHA-256 随 Release 附件。
