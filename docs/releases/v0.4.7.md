# 腕上导航 v0.4.7 · 手机后台退出修复

2026-11-13 发布；退出逻辑修复于 2026-11-12 完成本地构建。

开启「退出手机应用时退出手环」后，手机 0.3.0 会把回桌面、切到高德或其他应用当成退出，导致手环导航被关闭。本版手机 0.3.1 将挂后台与明确退出分开：切后台继续同步，只有从手机主页面按返回键或完成返回手势才按开关请求退出手环。

**配套版本：手机 0.3.1 / code16，手环 0.4.6 / code20。** v0.4.7 是本次发布编号，手环安装后的版本仍显示 0.4.6。本次手环两份 RPK 沿用 v0.4.6 已发布原字节，原包名与配对签名保持，APK/RPK 仍为原签名 debug 构建。

**已安装手环 0.4.6 的用户只需更新手机 APK**，完整字体与无字体版均兼容；首次安装需手机 APK 与手环 RPK 配套，手环两版选一，通过 AstroBox「快应用」安装。

| 文件 | 用途 |
| --- | --- |
| NAV-PHONE-031.apk | 手机 0.3.1 / code16，修复切后台误退出 |
| NAV-BAND-046.rpk | 手环 0.4.6 / code20，完整字体版，沿用原包 |
| NAV-BAND-046-NOFONT.rpk | 手环 0.4.6 / code20，无字体版，沿用原包 |
| TESTING.txt | 安装配对、行为和待真机验证范围 |
| THIRD_PARTY_NOTICES.txt | 完整版权与第三方许可 |
| SHA256SUMS.txt | 附件 SHA-256 校验表 |

两个手机联动开关独立保存、默认关闭。开启退出联动后，行为如下：

| 手机操作 | 手环行为 |
| --- | --- |
| 回桌面、切到高德或其他应用 | 保持运行，后台同步和导航自动打开继续 |
| 锁屏、进入系统权限设置、页面配置重建 | 不请求退出 |
| 仅关闭手机设置弹层 | 不请求退出 |
| 主页面按返回键或完成返回手势 | 请求退出手环；关闭退出开关时不联动 |
| 快速重新进入手机应用 | 取消待退出请求，保留进入联动 |

后台切换会停止本次进入联动重试，已经发出的 SDK 打开请求不能撤回；迟到打开仅在明确退出后才发送补偿退出。退出继续使用原 v1 phoneExitId、先 ACK、延迟约300ms执行、有限窗口与去重，快速重入可以取消待退出。手机后台同步服务保持运行。

本地验证：修复前两项回归测试失败；修复后 **67 项 Android 单元测试、131 项 Node 测试、Android Lint 与原签名 APK 构建通过**。新 APK 包名、版本和签名已核对，证书与旧手机及手环一致；两份 RPK 及完整许可与 v0.4.6 保持字节一致。发布附件按白名单、完整许可与 SHA-256 核对。

**本版修复尚未真机验收。** 切高德后持续更新、返回键/手势、设置弹层、锁屏/权限/配置重建、快速进出和耗电仍需实际设备回归。此前 K80U / 手环10 Pro 的试用及基础振动反馈不等于本版通过；其他手机未测试，9 Pro 自手环0.3.3起未回归。强杀/强停、系统回收、断连及固件/网络时序不保证退出；ACK只证明收到请求，不证明实际退出。Latest仅代表分发状态。

安装前请阅读 TESTING.txt，并核对随附 SHA256SUMS.txt。需要切高德继续导航时，本版可保持退出联动开启；历史手机0.3.0仍需关闭该开关。完整行为与实现说明见 [后台与退出修复](https://github.com/worlt/wrist-navigation/blob/v0.4.7/docs/phone-background-exit-031.md)。
