## 界面变化

- 手机、手环各自面板，设备小图标/标题/渠道标记帮助区分，不再把大段设置和更新说明混排。
- 优先显示「当前安装」与「GitHub 最新版本」。这里的GitHub最新是本端所选渠道按versionCode选出的候选，不是把Release标签当手机/手环版本。
- 手机也始终显示已获取的GitHub版本，即使已装版本相同或更高。正式/Preview标记独立，未完整确认时显示待确认，检查中显示确认中；未知手环明确未知。
- 检查结果与「版本详情」处于同一摘要行，主检查按钮浅绿，次发布页按钮弱化；更少纵向空白。窄屏/大字体下版本及摘要自动纵排，不截断版本号。
- 每端详情默认收起，展开显示Release标签、双端配套和正文；清理标题符号/粗体/代码标记并保留换行列表，内容仍为纯文本，不执行来自Release的指令/HTML/脚本。
- 手机/手环的展开状态独立，同一发布的异步检查不重置展开；候选发布变化或重新打开页面回到收起。详情展开/收起后重新限制弹层滚动高度，避免超出屏幕或收起留下长空白。
- 「自动检查」「Preview」收进下方默认折叠的「检查设置」，两端分别保存、默认行为不变。按钮/展开控件至少48dp，展开状态和按钮角色明确给读屏。
- 原浅绿配色、Android系统字体和明暗主题保持；没改导航/通知解析/互联/签名/手环/更新网络策略或自动安装行为。
