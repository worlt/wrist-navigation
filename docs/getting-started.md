# 首次使用

腕上导航需要 **Android 手机配套应用（APK）+ 小米手环 10 Pro 快应用（RPK）+ 小米运动健康连接**。高德地图继续在手机上负责导航。

## 获取安装包

想先看界面可打开 [在线演示](https://wrist-navigation.vercel.app/)；网站使用虚构数据，不连接设备，不能用于真实导航。演示的 0.4.0 功能可能先于已发布安装包，字体与其他边界见 [字体说明](fonts.md) 和 [验证摘要](navigation-verification.md)。

源码仓库不附带安装包或签名。`outputs/` 是维护者本地目录，克隆源码不会下载其中的文件。请从 [GitHub Releases](https://github.com/worlt/wrist-navigation/releases) 阅读发布说明，取得标明兼容的 APK、RPK，并核对发布正文或随附校验表中的 SHA-256。v0.2.5 的校验值写在发布正文，未单独附校验表。不要把无签名检查产物作为安装包。

[`v0.4.0（Latest）`](https://github.com/worlt/wrist-navigation/releases/tag/v0.4.0) 配套手机 0.2.5 / code 10、手环 0.4.0 / code 14，附完整校验表和第三方声明。维护者已在红米 K80 Ultra（K80U）上试用，其他手机因没有设备尚未测试；已有同版手机 APK 可仅更新 RPK。此前 [`v0.2.5`](https://github.com/worlt/wrist-navigation/releases/tag/v0.2.5) 配套手环 0.3.3，曾在**小米手环 10 Pro** 日常使用。9 Pro 自 0.3.3 起未再回归，**是否仍可用未经确认**。字体加载、滚动、设置保存、长时间锁屏与亮屏行为尚未获得逐项反馈，长期稳定性仍待验证。10 Pro 的适配范围与验收项见 [10 Pro 移植](port-10pro.md)。

## 配置顺序

1. 让小米运动健康正常连接手环；手机高德地图需能显示导航通知。
2. 在手机安装维护者提供的已签名 APK。手机 APK 与手环 RPK 的包名都应为 `io.github.mi9pro.navigation`，并使用匹配签名。
3. 在 AstroBox 使用“快应用”类型选择 RPK 安装到手环，具体连接步骤见 [手环安装指南](band-install.md)。不要将 APK 安装到手环，也不要选择重置设备。
4. 安装后恢复小米运动健康连接。打开手机腕上导航，按页面提示授予通知使用权、所需设备权限和互联授权，再开启同步。根据手机系统设置后台运行权限。
5. 在安全、可停留操作的位置，用高德开始导航，检查手环是否打开并显示相同指引。结束导航、关闭同步或离开页面后检查常亮释放。
6. 手环底部齿轮可调整显示，升级会保留旧设置。只有安装手环 0.4.0 后，“恢复默认”才使用本轮默认比例（字号 36、箭头 160、粗细 8、实心薄荷绿箭头、白色文字）；已发布 0.3.3 不包含本轮箭头与环岛更新。

如只显示等待状态，依次核对高德是否有导航通知、通知使用权、手机同步开关、运动健康连接与手环应用是否同签名。错误反馈请使用 [贡献指南](../CONTRIBUTING.md)，不要上传真实路线或设备凭据。

## 开发者自行编译

普通贡献者无需签名即可执行 JS 测试、界面预览与 Android 无签名编译。维护现有安装必须恢复原有双端签名，不能由安装包还原私钥。

独立 Fork 如需建立自己的应用身份，必须自行管理包名、双端匹配证书及升级路径；现有项目的构建入口默认保护原应用身份。不同签名不能作为现有发布版的覆盖更新，也不能将不同签名的手机与手环包混用。本 fork 使用自己的匹配证书，不能覆盖原作者身份的安装包；签名私钥不公开。
