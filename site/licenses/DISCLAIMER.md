# 项目与使用声明

## 项目定位与来源

腕上导航将 Android 高德地图的导航通知同步至小米手环 10 Pro，由手机高德负责路线规划；手环仅显示已有指引，不独立定位、计算路线或保证信息实时送达。项目用于学习、研究与技术交流；这是用途介绍，不为 MIT 增加“仅非商业”等限制。

本项目是 [Gu-Mie/wrist-navigation](https://github.com/Gu-Mie/wrist-navigation) 的修改版。原作者 Gu-Mie，当前 fork 维护者 worlt；保留双方及贡献者的版权。与高德、小米、AstroBox 或 Vercel 无隶属、合作或背书关系，相关名称仅说明兼容对象和工具。

## Release 状态与验证边界

2026-11-11 的 v0.4.6 按维护者要求作为正式 Release 并设为 Latest，配套手机 0.3.0 / code 15、手环 0.4.6 / code 20。**“正式 Release / Latest”是分发状态，不代表稳定性认证、厂商认证或本版真机验收完成。** APK/RPK 仍是复用原配对签名的 debug 构建，并非重新生成签名或已加固的生产构建。

当前已完成本地自动化、Lint、编译产物与原签名检查；本版新联动、各类双振提醒、熄屏/后台/锁屏、长时稳定性和耗电仍待真机测试。此前 K80U / 10 Pro 的试用、基础振动反馈不能扩展为本版全部功能通过；其他手机未测试，9 Pro 自 0.3.3 起未回归。SDK 发送成功、收到 ACK、实际显示/振动/退出是不同证据。

两个手机进出联动开关默认关闭，互相独立。启用“退出手机应用时退出手环”后，回桌面或切到高德也会请求退出手环，并抑制手机后台的通知自动重开；希望导航在后台持续展示时，请保持该开关关闭。锁屏、配置重建和主动进入权限设置不触发退出。强杀、强停、断连、系统回收及固件/网络时序不保证退出。

## 安全使用

请先在安全、静止的位置核对双端安装与显示，不要在驾驶、骑行或过街时操作手机或手环。通知可能滞后、缺失或误解析，振动可能延迟或不发生；不能用作避险、紧急服务或安全关键导航。应以实际道路状况、交通规则及手机高德指引为准。独立路线摘要（剩余时间/路程/全程里程）未实现。

## 隐私与分发

项目未实现自建服务器、分析/广告 SDK 或主动上传路线接口。通知仅处理 `com.autonavi.minimap`；路线和原文仍属于敏感信息，反馈前替换为虚构数据并裁去账号、设备标识。小米/高德及演示托管方的数据处理不受本项目控制，详见 [PRIVACY.md](PRIVACY.md)。源码、APK/RPK、截图与日志须分别检查，未检出凭据不等于绝无泄露。
