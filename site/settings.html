# 隐私与权限说明

本说明依据手机0.3.2、手环0.4.6及网页源码整理，更新时间2026-11-13；本版诊断和厂商行为尚待真机验证。代码检查不能代替第三方平台隐私承诺或完整设备测试。

## 处理哪些信息

Android 通知使用权是系统级能力；应用收到通知回调后只处理包名为 `com.autonavi.minimap` 的高德通知。通知中的标题、导航指引和原文用于解析、手机预览及手环显示，可能包含距离或道路名称。无法识别时保留原文，不补造路线。

应用通过小米 XMS SDK 与小米运动健康连接的手环通信。发送内容包含导航状态、标题/原文、解析字段、时间、会话、序号及本次导航标识、结束标记和独立振动偏好；导航标识只用于提醒去重，不含位置坐标。启用手机退出联动时增加一次性退出请求标识（phoneExitId），由会话和进出计数构成，只在进程内用于退出请求去重和确认，不包含路线内容；两个联动偏好保存在手机私有设置中，不新增权限。当前手机 / 手环源码没有项目自建的导航后端、广告或统计上报代码；小米 SDK、运动健康、高德和安装工具的数据处理由各自产品决定，不能据此承诺第三方完全离线或不收集数据。

手机设置保存在应用私有 SharedPreferences，导航状态和最近的诊断事件在进程内维护；手环显示设置与提醒震感通过 `system.storage` 分别保存；振动偏好仅存总开关与轻柔/明显档位，不新增路线历史。手环 App 在内存中保留一条最新导航消息，以及转向、临近两类各最多 32 条指令标识，以及开始、结束两类各最多 32 条导航标识用于去重；离开或关闭导航页面不会清除这些应用级状态。新的有效手机导航会话会重置提醒去重记录；App 销毁后停止处理，重建不保证保留这些内存状态。浏览器预览使用虚构数据，设置保存在当前浏览器。源码没有自行持久化完整路线历史；操作系统、第三方组件以及用户手动导出的日志仍可能留有数据。

## 在线演示与托管

[Vercel 演示站](https://wrist-navigation.vercel.app/) 只使用虚构场景，不接收高德通知，不读取设备位置，也不连接手机或手环。交互预览和设置原型将偏好保存在浏览器 `localStorage`；源码未将这些偏好上传。源码预览的“恢复全部预览默认值”可清除该页模拟设置；清除站点数据可删除此域名下的全部本地偏好。

访问站点会向 Vercel 发出网络请求，托管方可能处理 IP 地址、浏览器 / 设备信息、访问路径及时间等请求数据，适用其 [隐私政策](https://vercel.com/legal/privacy-policy)。本项目未接入分析 SDK；仅核对公开页面与生成代码，未审计托管账户的日志、分析或保留期限设置，因此不承诺“零日志”或“完全离线”。点击 GitHub、字体来源等外部链接后，适用目标站点的规则。

网站展示的联系邮箱是项目公开联络方式。不要在公开反馈中填入真实路线、住址、设备凭据或完整日志。

## 为什么需要权限

| 权限/能力 | 用途 |
| --- | --- |
| 通知使用权 | 获取高德导航通知；可在系统设置中撤销 |
| 蓝牙/附近设备、互联授权 | 通过小米运动健康发现并连接手环 |
| 发送通知、前台服务 | 显示后台同步状态和停止入口 |
| 唤醒锁、电池优化设置 | 活动导航期间尽量保持同步；受手机省电策略影响 |
| 开机完成/应用更新广播 | 尝试恢复此前开启的同步，真机重启恢复仍待验证 |
| 手环亮屏控制 | 导航页在前台且指引有效时保持点亮 |
| 手环振动 | 收到导航开始、确认结束、新转向、临近或暂停状态，以及确认连接断开时触发两次短振或长振；手机开关控制导航提醒，手环总开关控制全部提醒和试振 |

关闭手机应用中的同步开关可停止转发；通知使用权和其他权限也可从系统设置撤销。手环离开导航页、断连或消息过期后释放常亮，但离开导航页本身不会关闭应用级接收与振动提醒。要停止后续提醒，可关闭手环振动总开关、手机导航偏好中的手环振动开关或关闭同步；恢复开关不会补振已消费的提醒。

断连提醒仅使用手环最后收到的手机振动偏好；断连后手机修改开关需恢复通信才会传达，手环本地总开关可立即关闭全部提醒。

手动试振无需导航，在手环总开关开启时按当前档位振两下；离开设置或隐藏页面会取消尚未发出的试振，不影响正常导航提醒。

当前 Android 清单没有申请 VIBRATE 权限，也没有新增手机振动；高德自身的手机提醒不由本项目控制。此次优化未新增定位、音频或下载能力，不借用这些能力保活。手环 App 仍运行且收到有效实时消息时才尝试振动，后台、熄屏和回表盘后的运行、收消息及振动仍取决于固件与互联，需真机测试。

手机0.3.2首页诊断默认折叠，内存中有界保留高德通知字段、解析、提交发送和确认状态，不自动写文件、路线日志或上传。用户点击「复制当前诊断」后才写入系统剪贴板，包含手机型号、Android版本、应用版本、采集时间与通知文字；分享前需移除真实路线。
