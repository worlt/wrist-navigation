# 隐私与权限说明

本说明依据手机0.3.6、手环0.4.8本地候选及网页源码整理，更新时间2026-11-18；更新检查、诊断和厂商行为尚待真机验证。代码检查不能代替第三方平台隐私承诺或完整设备测试。

## 处理哪些信息

Android 通知使用权是系统级能力；应用收到通知回调后只处理包名为 `com.autonavi.minimap` 的高德通知。通知中的标题、导航指引和原文用于解析、手机预览及手环显示，可能包含距离或道路名称。无法识别时保留原文，不补造路线。

应用通过小米 XMS SDK 与小米运动健康连接的手环通信。发送内容包含导航状态、标题/原文、解析字段、时间、会话、序号及本次导航标识、结束标记和独立振动偏好；导航标识只用于提醒去重，不含位置坐标。启用手机退出联动时增加一次性退出请求标识（phoneExitId），由会话和进出计数构成，只在进程内用于退出请求去重和确认，不包含路线内容；两个联动偏好保存在手机私有设置中，不新增权限。当前手机 / 手环源码没有项目自建的导航后端、广告或统计上报代码；小米 SDK、运动健康、高德和安装工具的数据处理由各自产品决定，不能据此承诺第三方完全离线或不收集数据。

手机设置保存在应用私有 SharedPreferences，导航状态和最近的诊断事件在进程内维护；手环显示设置与提醒震感通过 `system.storage` 分别保存；振动偏好仅存总开关与轻柔/明显档位，不新增路线历史。手环 App 在内存中保留一条最新导航消息，以及转向、临近两类各最多 32 条指令标识，以及开始、结束两类各最多 32 条导航标识用于去重；离开或关闭导航页面不会清除这些应用级状态。新的有效手机导航会话会重置提醒去重记录；App 销毁后停止处理，重建不保证保留这些内存状态。浏览器预览使用虚构数据，设置保存在当前浏览器。源码没有自行持久化完整路线历史；操作系统、第三方组件以及用户手动导出的日志仍可能留有数据。

## GitHub 更新检查

手机0.3.6将「软件更新」拆为手机、手环两组，各自自动检查、手动按钮与独立Preview勾选。自动检查默认开启，仅在打开应用时按每渠道24小时尝试一次，可关闭或手动检查；手机与手环「接收 Preview 更新提示」各自默认不勾选，可选择包含GitHub Pre-release。查询固定公开仓库 `worlt/wrist-navigation` 的Release和 `update.json` 附件，不使用GitHub账号、令牌，不上传高德通知、路线、诊断、手机型号或设备标识。开关、检查时间和公开版本元数据缓存仅保存在应用私有设置中。

检查与点击发布页会向GitHub及其下载域发出网络请求，平台可处理IP地址、请求路径、时间及固定应用User-Agent，适用 [GitHub隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。不承诺第三方零日志；无法访问/限流不影响导航。不自动下载安装；已装手环版本来自当前已授权连接中手环应用的包名/name/code报告，只在手机内存判断，不发给GitHub，断连清空；旧版/未连接明确未知。下载和覆盖安装由用户在外部工具完成。关闭自动检查不会取消已经发出的请求；切换实验渠道可能触发一次主动检查，手动点击仍会联网。具体边界见 [双端更新提示说明](docs/phone-band-updates-036.md)。

## 在线演示与托管

[Vercel 演示站](https://wrist-navigation.vercel.app/) 只使用虚构场景，不接收高德通知，不读取设备位置，也不连接手机或手环。交互预览和设置原型将偏好保存在浏览器 `localStorage`；源码未将这些偏好上传。源码预览的“恢复全部预览默认值”可清除该页模拟设置；清除站点数据可删除此域名下的全部本地偏好。

访问站点会向 Vercel 发出网络请求，托管方可能处理 IP 地址、浏览器 / 设备信息、访问路径及时间等请求数据，适用其 [隐私政策](https://vercel.com/legal/privacy-policy)。本项目未接入分析 SDK；仅核对公开页面与生成代码，未审计托管账户的日志、分析或保留期限设置，因此不承诺“零日志”或“完全离线”。点击 GitHub、字体来源等外部链接后，适用目标站点的规则。

网站展示的联系邮箱是项目公开联络方式。不要在公开反馈中填入真实路线、住址、设备凭据或完整日志。

## 为什么需要权限

| 权限/能力 | 用途 |
| --- | --- |
| 网络（INTERNET） | 读取GitHub公开版本信息；不发送导航或诊断 |
| 通知使用权 | 获取高德导航通知；可在系统设置中撤销 |
| 蓝牙/附近设备、互联授权 | 通过小米运动健康发现并连接手环 |
| 发送通知、前台服务 | 显示后台同步状态和停止入口 |
| 唤醒锁、电池优化设置 | 活动导航期间尽量保持同步；受手机省电策略影响 |
| 开机完成/应用更新广播 | 尝试恢复此前开启的同步，真机重启恢复仍待验证 |
| 手环亮屏控制 | 导航页在前台且指引有效时保持点亮 |
| 手环振动 | 收到导航开始、确认结束、新转向、临近或暂停状态，以及确认连接断开时触发两次短振或长振；手机开关控制导航提醒，手环总开关控制全部提醒和试振 |

关闭手机应用中的同步开关可停止转发；通知使用权和其他权限也可从系统设置撤销。手环离开导航页、断连或消息过期后释放常亮，但离开导航页本身不会关闭应用级接收与振动提醒。要停止后续提醒，可关闭手环振动总开关、手机导航偏好中的手环振动开关或关闭同步；恢复开关不会补振已消费的提醒。

断连提醒仅使用手环最后收到的手机振动偏好；断连后手机修改开关需恢复通信才会传达，手环本地总开关可立即关闭全部提醒。

手动试振无需导航，在手环总开关开启时按当前档位振两下；离开设置或隐藏页面会取消尚未发出的试振，不影响正常导航提醒。

当前 Android 清单没有申请 VIBRATE 权限，也没有新增手机振动；高德自身的手机提醒不由本项目控制。此次优化未新增定位、音频或下载能力，不借用这些能力保活。手环 App 仍运行且收到有效实时消息时才尝试振动，后台、熄屏和回表盘后的运行、收消息及振动仍取决于固件与互联，需真机测试。

手机0.3.2首页诊断默认折叠，内存中有界保留高德通知字段、解析、提交发送和确认状态，不自动写文件、路线日志或上传。用户点击「复制当前诊断」后才写入系统剪贴板，包含手机型号、Android版本、应用版本、采集时间与通知文字；分享前需移除真实路线。

## 兼容试验诊断（手机0.4.0 / 手环0.5.0）

手环没有新增排查模式或诊断界面。内部只在内存保留最近16条阶段、错误类型与数值代码、有界计数，不保存原始封包、路线或错误message/stack，进程结束后丢失。手机用户点击“读取手环诊断”才发起一次查询，接收限定当前授权设备、当前请求和5秒时限；旧报告标为历史，不自动重试或上传。

“复制兼容诊断（无路线）”只包含手机型号/系统/应用版本、手环应用版本、协议/收发计数和白名单阶段，不含通知和路线。用户点击后才写剪贴板，由用户决定是否分享。原“复制当前诊断”仍包含通知原文，分享前需脱敏。手机不能读取手环安装器和固件崩溃日志，无法启动时需用户工具日志或照片，不能以超时冒充已定位原因。详见[兼容反馈指南](docs/band9-band10-compatibility.md)。

# 项目与使用声明

## 项目定位与来源

腕上导航将 Android 高德地图的导航通知同步至小米手环 10 Pro，由手机高德负责路线规划；手环仅显示已有指引，不独立定位、计算路线或保证信息实时送达。项目用于学习、研究与技术交流；这是用途介绍，不为 MIT 增加“仅非商业”等限制。

本项目是 [Gu-Mie/wrist-navigation](https://github.com/Gu-Mie/wrist-navigation) 的修改版。原作者 Gu-Mie，当前 fork 维护者 worlt；保留双方及贡献者的版权。与高德、小米、AstroBox 或 Vercel 无隶属、合作或背书关系，相关名称仅说明兼容对象和工具。

## Release 状态与验证边界

v0.5.2作为正式Latest分发，配套手机0.4.2/code27与手环0.5.1/code25。**正式Release/Latest是分发状态，不代表厂商认证或全部功能/所有设备稳定性认证。** APK/RPK仍沿用原配对签名的debug构建；手环051原包不变。

仅在小米 15 + 小米手环 9 Pro、K80 Ultra + 小米手环 10 Pro 两组组合获得用户真机测试正常反馈。其他米系手机通常预期能运行，但未经逐型号验证；其他品牌手机不一定能用，不保证可用。可能受运动健康互联、通知样式或后台策略影响。 这两组是用户真机反馈，不能扩展为全部功能、所有固件或手机042新UI已实测。SDK提交、ACK、屏幕实际显示/振动/退出是不同证据。字体、后台/息屏、长期连接与耗电仍需按具体设备验证。

两个联动开关独立保存且默认关闭。回桌面/切高德保持后台同步，开启退出联动时仅主页面正常返回退出请求关闭手环；只关闭设置弹层不退出手环。开启“退出手机应用时退出手环”后，直接杀掉或清理手机后台时，进程可能来不及向手环发送退出通知，因此手环无法跟随退出；从手机主页面正常按返回键或返回手势退出，有用户正常反馈。只关闭设置弹层不触发手环退出。强停、断连、系统回收同样不保证退出。

## 安全使用

请先在安全、静止的位置核对双端安装与显示，不要在驾驶、骑行或过街时操作手机或手环。通知可能滞后、缺失或误解析，振动可能延迟或不发生；不能用作避险、紧急服务或安全关键导航。应以实际道路状况、交通规则及手机高德指引为准。独立路线摘要（剩余时间/路程/全程里程）未实现。

## 隐私与分发

项目未实现自建服务器、分析/广告 SDK 或主动上传路线接口。通知仅处理 `com.autonavi.minimap`；路线和原文仍属于敏感信息，反馈前替换为虚构数据并裁去账号、设备标识。小米/高德及演示托管方的数据处理不受本项目控制，详见 [PRIVACY.md](PRIVACY.md)。源码、APK/RPK、截图与日志须分别检查，未检出凭据不等于绝无泄露。
